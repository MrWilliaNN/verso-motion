# Verso Motion

Editor web de letras animadas para projeção em cultos, transmissões e redes sociais.

## Executar localmente
Abra o arquivo `index.html` em um navegador moderno. A versão atual é um app independente em HTML, CSS e JavaScript, sem etapa de build.

## Funcionalidades atuais
- Criar, editar, dividir, adicionar e excluir cenas.
- Personalizar texto, fontes, cores, destaques e animações.
- Configurar fundos animados e visualizar as cenas.
- Reproduzir prévia, usar tela cheia e avançar cenas automaticamente.
- Salvar/carregar projeto em JSON.
- Exportar o vídeo completo em WebM.
- Exportar cada cena separadamente em WebM.

## Limitações conhecidas
- O áudio do player não é incorporado ao vídeo exportado.
- A renderização de exportação pode diferir de algumas animações da prévia.
- Antes de mudanças grandes, teste o fluxo de edição, a prévia e as duas opções de exportação.
